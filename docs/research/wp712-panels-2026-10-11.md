## Native transport

`DeviceHubProxy.ts:35-58,175-185` restricts the endpoints and reads `hostId`; credentials never go directly to the helper. `packages/client-runtime/src/state/deviceHubAccess.ts:1-16,40-72` mints a fresh, reusable five-minute wsTicket. Both paths are derived from the connected environment URL, with encoded device IDs and query fields. T3 Connect uses the existing EnvironmentHTTP authorizer.

The iOS MJPEG request primes capture before resuming the input socket, matching `stream.ts:729-753`. JPEG extraction has a 16 MB ceiling. The existing bounded FrameDecoder decodes off the main thread, keeping only the newest waiting image. Android converts SEMU Annex-B access units to AVCC samples and uses VideoToolbox on an actor. Parameter-set changes require a keyframe. There is no polling, display link, background browser or repeating retry timer. Hiding the panel, switching threads or occluding the window cancels state subscriptions, HTTP, sockets and decoder state. A failure is visible and Refresh reconnects.

Deliberate remaining ceiling: reconnect is manual; add fresh-ticket automatic reconnect and first-frame timeout with live runtime coverage. iOS uses T3's supported MJPEG fallback rather than H.264. Measure CPU with a live simulator before declaring performance parity.
