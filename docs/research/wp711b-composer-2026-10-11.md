## Remaining work

- Rich blocks need exact vertical rhythm, wrapped indentation and native structural splitting. HTML paste is still the existing context-fragment/plain-text path. Selection mapping across formatting and refreshed chips needs a complete position map; this implementation is not a full Tiptap node model.
- Fences need syntax highlighting, searchable picker, fence lengthening around pasted fences and blank-line exit. Empty-caret formatting needs wider typing/inheritance coverage.
- Preview needs sent/question files, Copy and exact panel layout. Custom models need presets, built-in model copying and visual matching.
- Server update needs its M9 producer, spinner and stacked peek. Collapse needs every eligibility gate and on-screen long-timeline validation. Multi-model uncertain-failure retry remains outside this change.
- Actions still lack draft row, t3.json import and preview URL opening. Auth lacks credential/device-code/manual-callback/sign-out forms and exact inline placement. No real sign-in was started.
- New pixel fidelity covers inline rich text only; block, resting, auth, custom-model and preview states still need official captures and comparisons.
