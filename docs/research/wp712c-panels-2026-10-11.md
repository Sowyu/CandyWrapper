## Implemented

- Submitted diff cards use the existing annotation layout and composer context records. A card has the primary border, comment icon, wrapped text and hover delete action. Double-click or its context menu opens the editor; Save updates the existing record without adding a duplicate chip. Delete removes its chip, and deleting a chip removes its card. Records are persisted with referenced saved prompts. Anchors match the excerpt's final line by side, number, kind and content, so a changed patch cannot silently anchor a card to unrelated code. Sources: `apps/web/src/components/diffs/DiffCommentAnnotation.tsx:68-145`, `AnnotatableCodeView.tsx:124-193`, `apps/web/src/reviewCommentContext.ts:367-456`. Unsubmitted draft persistence, drag ranges and file-preview producers remain.
- Sheet entry takes focus, Tab and Shift-Tab stay among visible enabled panel controls, Escape dismisses an annotation draft first and then the sheet, and closure restores the previous responder. Nested native modals retain their own key handling. This uses the existing `Shortcuts` dispatcher, with no added monitor. Source: `apps/web/src/components/RightPanelSheet.tsx:13-30`, `components/ui/sheet.tsx` delegates modality to the base dialog. Transition timing remains.
- Host summaries decode capability flags, per-host lifecycle status, tool inspection errors and required/installed/running versions. Failed hosts expose supported retry; version details expose supported hub/agent updates. Settings adds an on-demand, per-environment inventory using `device.list {inspectOnly:true}`; it does not enable support or install tools. Closing its dialog cancels work. Sources: `packages/contracts/src/device.ts:77-163`, `apps/web/src/components/device/DeviceHostUpdates.tsx:24-74`, `DeviceToolVersions.tsx:28-132`, `DeviceHostAvailability.tsx:11-34`. - Browser profiles now report custom profiles and the normalized default on discovery, reconnect and relevant client-setting changes. Sources: `apps/web/src/browser/BrowserProfileReporter.tsx:17-42`, `packages/contracts/src/preview.ts:297-304`. This intentionally corrects WP7.12b's decision to omit reporting: agents otherwise cannot discover custom names. Coexistence follows the official last-writer-wins server implementation (`apps/server/src/preview/ServerBrowser.ts:1250-1277`). There is no atomic merge or ownership lease; an official client can replace this report and vice versa. Reports affect server memory, not stored cookies. Scope rejection is server-enforced and best effort. Exact inline profile rows and viewport presets remain.
